# Account Statement PDF

PDF is generated by the **Coditium Python report service** and proxied through PMS.

| Item | Value |
|------|--------|
| API docs | Repo root `api.txt` |
| Production base URL | `http://34.131.132.158:8000` |
| Endpoint | `GET /api/reports/account-statement?customerId={CustomerID}` |
| PMS proxy | `GET /Report/AccountStatement?accountNo={CustomerID}` |
| Config | `ReportService:BaseUrl` in `appsettings.json` |
| Client | `Services/ReportServiceClient.cs` |

Example: [http://34.131.132.158:8000/api/reports/account-statement?customerId=CK00004](http://34.131.132.158:8000/api/reports/account-statement?customerId=CK00004)

On-screen statement (HTML): `/Customer/AccountStatement/{accountNo}`

## History

Earlier Linux in-process ReportViewer / Wine / LibreOffice approaches were removed from the PMS VM. Do not reinstall Wine/LibreOffice for PDF on the Ubuntu PMS host.
